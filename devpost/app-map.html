Project guide

Dawa Equips Marketplace

A marketplace for refurbished commercial appliances. Buyers inspect equipment, place an order, receive a draft invoice, and track fulfillment. The vendor portal advances orders and updates invoice and stock records.

Follow one order

Reference route through the code

This is a reference route; it is not a record of a live code tour.

  1. client/src/components/storefront/CartCheckoutDrawer.tsx — find handleSubmitOrder. It checks the buyer fields, turns cart rows into order items, and calls the API helper.
  2. client/src/lib/api.ts — find createOrder and trackOrdersByPhone. These functions connect the interface to the order endpoints.
  3. server/routes/orders.ts — find POST /api/orders and PATCH /:id/stage. The route saves the order and invoice; delivery updates invoice status and product stock.

A practice to reuse

The approved PRD’s Core Journey names checkout, fulfillment, and tracking in order. The checklist then ties each usable slice to a mechanical verification command and a learner check. On another project, write the user-visible outcome first, then connect it to the code path and evidence that would show it works.

Run it again

From the project root, run npm run dev to start the client and server. The server needs the project’s configured database environment. Open the local address printed by Vite; use /vendor for the vendor portal.
